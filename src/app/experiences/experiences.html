Codethon 1ª Edición

Desarrollo de una aplicación web para usuarios de vehículos eléctricos, creada con Angular y Spring Boot. El proyecto permite visualizar puntos de carga estáticos y consultar información detallada de cada cargador. Además, ofrece una funcionalidad de planificación de rutas dinámicas, permitiendo al usuario visualizar cargadores cercanos a su trayecto y añadir paradas personalizadas.
